# Roadmap

> **These are ideas, not promises.** No dates, no guarantees, and the order can change. Some may never ship. What you ask for in issues and 👍 reactions moves things up.

## Being looked at

- **More services.** Driven by [service requests](../../issues?q=label%3Aservice-request). Most-upvoted first.
- **Install updates for more services.** Today: Home Assistant, TP-Link Omada devices and non-Docker Sonarr/Radarr/Prowlarr. Others only if their API allows it safely, and always with a confirmation.
- **More detail for existing services.** E.g. deeper views for NAS and network gear.
- **More languages.** English and Spanish today.

## Maybe later

- More import sources from other dashboards.
- More Siri and Shortcuts actions.
- More widget layouts.

## Not planned

- **Android.** LabDeck is a native iPhone/iPad app.
- **An account, a cloud relay or a LabDeck server.** The app talks straight to your services.
- **Analytics or tracking.**
- **A subscription.** Pro is a one-time purchase.

Have an idea? [Open a feature idea](../../issues/new?template=feature_idea.yml) or start a [discussion](../../discussions).
